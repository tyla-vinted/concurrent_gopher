# Concurrent Gopher

| Command | What it does |
|---|---|
| `make doctor` | Checks that Go and the build work on this laptop. |
| `make run <function>` | Shows your function on the factory floor. Press `q` to quit. |
| `make check <function>` | Tests the lesson of your function, and tells you what to fix first. |
| `make hint <function>` | Gives a hint for the first failing test. Run it again for the next hint. |
